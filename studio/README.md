# Exodon AI Development Studio

## Status
Deferred / concept stage

The AI Development Studio will eventually become Exodon's internal operating system for coordinating:
- Orchestrator
- Research & Validation
- Product Management
- Architecture
- UX/UI
- Development
- QA / Review

Do not build the full Studio until the seven-agent workflow has been proven manually on Exodon and initial client projects.

The Studio should automate proven work, not automate assumptions.
