# Exodon Product Strategy

## Product Definition

Exodon is not primarily a SaaS product.

Exodon is a **service-led AI business systems company** supported by reusable internal technology.

## Customer Outcome

The customer should end with a business system better aligned with how the company actually operates.

## Productized Service Model

### 1. Discover

Deliverable examples:
- workflow map
- software stack map
- operational bottlenecks
- opportunity list
- build-vs-buy-vs-integrate recommendation
- Smart Layer blueprint

### 2. Build

Deliverable examples:
- custom web application
- operational dashboard
- employee portal
- customer portal
- custom workflow module
- integration

### 3. Automate

Deliverable examples:
- AI agents
- alerts
- scheduled workflows
- customer follow-up
- document processing
- reporting automation

## Product Principles

1. Business problem before software.
2. Existing software first.
3. Custom code only where it creates value.
4. AI only where measurable value exists.
5. Design for reuse.
6. Make client-specific behavior configurable when possible.
7. Human approval for high-risk actions.

## Success Metrics — Initial

- qualified discovery submissions
- consultations booked
- discovery-to-project conversion rate
- average project value
- recurring support revenue
- percentage of components reused
- implementation cycle time
- client administrative hours saved
- reduction in manual steps
