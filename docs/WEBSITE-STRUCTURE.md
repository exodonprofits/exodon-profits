# ExodonProfits.com — Website Structure

## Website Goal

Educate → demonstrate → qualify → capture.

The website should not attempt to run the complete Exodon delivery operation.

## Primary Navigation

- Home
- How It Works
- Services
- Smart Layer
- Case Studies
- About
- Start a Project

## Home Page

### 1. Hero

**Keep what works. Build what's missing. Automate what slows you down.**

Supporting message:
Exodon builds custom business systems around the software and workflows you already use.

Primary CTA:
**Tell Us What's Slowing You Down**

Secondary CTA:
**See How It Works**

### 2. The Problem

Message:
Your business may use more software than ever, yet critical work is still handled manually.

Show examples:
- disconnected tools
- duplicate entry
- spreadsheets
- missed follow-ups
- manual reporting
- custom rules existing software cannot handle

### 3. Discover / Build / Automate

Three concise pillars.

## Start a Project Page

The intake should ask:
- What does your business do?
- What software do you already use?
- What work is still manual?
- What frustrates your team?
- What do customers complain about?
- What do you wish happened automatically?
- What is the business impact?
- What result would make the project successful?

Avoid asking customers to design the solution for us.
