## Core Decision
Exodon will pursue a service-led **AI Business Systems** model centered around the **Exodon Smart Layer** rather than competing primarily as another general SaaS company or generic AI automation agency.

## Core Promise
**Keep what works. Build what's missing. Automate what slows you down.**

## Strategic Model
DISCOVER → BUILD → AUTOMATE → EXODON SMART LAYER

## Key Strategic Risks
1. Generic AI-agency positioning
2. Excessive customization
3. High support burden
4. Building features existing SaaS already provides
5. Unclear measurable ROI
6. Over-automation / AI trust risk
7. Unsupported third-party integrations
8. Weak or unfocused customer acquisition

## Required Product-Strategy Decisions
1. Define the first target customer narrowly.
2. Define the Smart Layer Blueprint / Discover deliverable.
3. Define what an MVP client engagement includes.
4. Define implementation boundaries.
5. Define recurring support/optimization model.
6. Define measurable customer outcomes.
7. Define what Exodon explicitly will not build.
